# Skill Pack

Agent skills for everyday Git work.

## Install

```bash
npx skills add acme/skill-pack
```

## Skills

| Skill                                            | What it does                                     |
| ------------------------------------------------ | ------------------------------------------------ |
| [commit-message](skills/commit-message/SKILL.md) | Writes a commit message from your staged changes |
| [pr-summary](skills/pr-summary/SKILL.md)         | Summarizes a pull request for reviewers          |
